Torna leíró JSON készítése

Új torna esetén hozz létre egy almappát az index.html mellett. Az almappába kerüljön a torna.json és minden, a tornához tartozó kép.

torna-app/
├── index.html
├── config.json
├── szemelyek.json
└── Billa_reggelinyujtas/
    ├── torna.json
    ├── torzscsavaras.jpg
    ├── mellkasnyitas.jpg
    └── ...

A torna JSON szerkezete

{
  "tornaId": "Billa_reggelinyujtas",
  "tornaReszletesNeve": "5 perces reggeli nyújtás",
  "feladatok": [
    {
      "nev": "Dinamikus Törzscsavarás",
      "hosszMasodperc": 30,
      "kep": "torzscsavaras.jpg",
      "leiras": "...",
      "automatikus_kovetkezo": false
    }
  ]
}

Az automatikus_kovetkezo mező minden feladatnál külön szabályozza a továbblépést: true esetén az idő lejártakor automatikusan indul a következő feladat; false vagy hiányzó mező esetén a Következő gombot kell megnyomni. Az alapértelmezés false. A kep mezőben a torna mappájában található fájl neve szerepeljen.

Edzésnapló letöltése

Az alábbi gomb a böngészőben tárolt teljes edzésnaplót letölti, tehát minden személy minden rögzített edzését tartalmazza.

A fájl neve: edzesnaplo.json.

JSON feltöltés

A JSON feltöltés a config.json alapján le van tiltva.

A korábban letöltött edzesnaplo.json fájl tartalmát vissza lehet tölteni a böngésző helyi edzésnaplójába.

Ez a művelet nem küld adatot szerverre. A fájl tartalma a böngésző localStorage-ába kerül.
